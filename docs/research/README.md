# Research

- [Plugins similares a wm](plugins-similares-a-wm/report.md), 2026-10-06, in Spanish. It surveys the Claude Code workflow plugins and frameworks with a vision like wm's: spec-driven frameworks, plugin ecosystems, model routing and cost, and enforcement and evaluation. Its prioritized improvements shaped wm 2.0. The researchers' notes, with their sources, are in [`notes/`](plugins-similares-a-wm/notes/).
